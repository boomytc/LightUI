# 读图

图画好之后，这一手是读数、过滤还是改窗口。选图种是另一问；看板层递也是另一问。

## 问题

「给图表加点交互」描述的是外观：鼠标移上去有反应。真正会坏掉的是**这一手改了不该改的状态**：

- 图例被当成颜色说明，点了却把唯一一条线藏掉
- 十字线拖着整张图跳，读一个点变成改窗口
- 框一段本来要算均值，松手却把轴缩进去
- 点一根柱换了图种，路径其实没变
- 读数卡撑开了图，离开后图还在抖
- 下钻被做成再开一张看板
- 指针吸附到最近的点，却被做成视线落到格子

用同一种 hover 去扛这些差异，不是读数被做成过滤，就是过滤被做成缩放。

## 规则

先问这一手是读、滤、框、窗还是换路径，再绑指针。

| 手势 | 类 | 规则 |
| --- | --- | --- |
| 十字线 / 高亮 / 读数卡 | **读数** | 吸附最近下标。离开就藏。高亮叙事点（异常低点或峰值），其余变淡。读数卡绝对定位，图的尺寸锁定 |
| 图例 | **过滤** | 切换系列显隐。不能把最后一条可见系列藏掉 |
| 框选 | **区间** | 按下记原点，拖出含端区间，松手冻结。用区间算均值和峰值。不改展示窗口 |
| 缩放 | **窗口** | `[start,end]` 切片。滚轮或 30 / 7 / 3，绕光标缩放，跨度至少 `minSpan` |
| 下钻 | **路径** | 有子节点才推进 child id；叶子不推。面包屑弹出。同一张图上的路径，不是看板从结果往下钻 |

最容易混的三对：

- **图例是过滤态不是装饰。** 点图例改的是哪些线在场。装饰色块不能把最后一条藏掉。
- **下钻换路径不是换图种。** 图种回答这组数据要看什么。点柱推进的是渠道 → 分类 → 页面。
- **框选冻结不是缩放窗口。** 框选留下一段、算出均值峰值，轴还在原来的窗。缩放才改 `[start,end]`。

最近邻吸附是读点，不是视线落到格子。图上 `round` 到下标；视线那一问是把偏移量化到图集格。

说清楚这一手，用三件事：

1. **名称** — 不要说「加点交互」
2. **场景** — 看一个点、藏一条线、框一段算均值、滚轮改窗，还是点柱换层
3. **规则** — 离开就卸、最后一条不能藏、框选冻结不是缩放、叶子不推进路径

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律做成 tooltip」的差别

| | 一律 tooltip | 按读 / 滤 / 窗分 |
| --- | --- | --- |
| 看一个点 | 卡片撑开图 | 读数卡离开即卸，尺寸锁 |
| 藏一条线 | 图例只是色块 | 过滤，最后一条留下 |
| 框一段 | 变成缩放 | 冻结区间，出均值峰值 |
| 看近一周 | hover 不改窗 | `zoomWindow` 绕光标切 `[start,end]` |
| 渠道往下 | 换一张饼 | 同一柱图推进路径 |

## 机器

判断在无 DOM 的模块里：`gestureClass`、`nearestIndex`、`brushPointerDown/Move/Up`、`rangeStats`、`legendToggle`、`zoomWindow`、`drillPush` / `drillPop`。
