# 路径变形

矢量路径与图标状态切换。先定**用 2D Procrustes 分解刚体旋放与极坐标残差，还是粗暴按坐标点硬插值**；转角靠等弧长角点锚定，子路径靠满射同位分裂。

## 问题

在菜单/关闭、播放/暂停、方向箭头等微交互中，「做一个路径变形」最容易犯的错误是**把所有点直接当作笛卡尔坐标 $(1-t)A + tB$ 线性插值**：

- **弦长塌陷**：右箭头转下箭头时，旋转顶点抄对角线近路，中间帧向中心收缩近 30%，图形缩成一团
- **剪切变形**：正交十字变对角叉号时，路径沿轴线互相挤压，中间态扭曲成缩小的菱形
- **大回环翻转**：对称直线正反两个方向残差相等，朴素算法容易挑中 135° 大翻转，而不是就近折叠 ±45°
- **生硬突变**：1 根线变 2 根柱子时，缺少子路径配对机制，导致图形从单一零尺寸点突然爆开或凭空消失
- **角点软化**：采样点未对齐真实拐角，静止状态下的尖角和对勾在变形途中被抹圆

为每对图标手动配置关键帧和旋转组虽然可行，但维护成本极高，无法通用。

## 规则

把几何变形拆为相似变换求解与极坐标空间插值：

| 机制 | 数学/几何模型 | 解决的问题 |
| --- | --- | --- |
| **2D Procrustes 对齐** | $\theta^* = \operatorname{atan2}(S_{xy}-S_{yx}, S_{xx}+S_{yy})$ | 闭式解自然涌现最优旋转角 $\theta^*$ 与缩放 $\sigma^*$，无需人工分组 |
| **极坐标分解插值** | $P(t) = c(t) + \sigma^t R(t\theta) [(1-t)a + t\tilde{b}]$ | 刚体在极坐标空间线性旋转，彻底杜绝弦长塌陷与向内缩小 |
| **角点锚定等弧长重采样** | 8 点高斯-勒让德积分 + 切线拐角检测 | 端点精确重合，静止态 100% 保真，途中角点平滑展开与锐化 |
| **满射配对与细胞分裂** | 质心距离加权配对 + 邻近子路径原地复制 | 子路径数不等时（如播放转暂停）原地分裂，视觉自然连续 |
| **最小旋转偏置 $\lambda$** | $\text{score} = \text{res} + \lambda \cdot |\theta| / \pi$ | 直线反演对称时自动选取最短角度（±45° 而非 135°） |
| **全局刚体混合** | 全局质心 Block Transport 刚体转动 | 全局全等图形（如箭头头部与尾柄）旋转时质心不往内凹 |

## 和「朴素坐标插值」的差别

| | 朴素坐标插值 (Linear Lerp) | 极坐标 Procrustes (Polar) |
| --- | --- | --- |
| **右箭头转下箭头** | 沿对角线走，中间帧缩小塌陷 | 绕质心刚性旋转 90°，尺寸饱满 |
| **汉堡线转叉号** | 容易发生 135° 翻转大回环 | $\lambda$ 偏置锁定最短 ±45° 优雅折叠 |
| **单路径转双柱** | 从一点凭空出现或消失 | 原地复制并分裂（细胞分裂） |
| **中间帧观感** | 软绵、缩小、剪切变形 | 刚劲有力、自然顺滑、物理连续 |

## 机器

流水线全部为无 DOM 纯数学计算：`resampleIcon`（8 点高斯积分 + 角点检测）$\to$ `buildPlan`（Procrustes 闭式解 + 满射分裂 + $\lambda$ 偏置）$\to$ `interpPolar`（极坐标相似插值）$\to$ `serialize`。单次 plan 规划仅需 0.01~0.4ms，支持任意帧率与物理外推。
