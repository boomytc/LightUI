# 长按上下文

触控长按目标时，手势如何在误触位移与持续时间中消歧，并在目标就近定位上下文操作？先定**原地长按时间门限与手抖位移注销机制，以及就近就地锚定并带边界翻转的浮层定位模型**。

## 问题

「长按出菜单」只描述了触发结果。真正会坏掉的是**时间位移未消歧导致手势打架，以及定位模型粗暴失衡**：

- **无位移容差，手抖即失败**：要求手指在半秒内纹丝不动，手指生理性微弱呼吸颤动（2–4px）导致长按判定频繁被打断失败，用户产生强烈的挫败感；
- **无位移注销，吞掉滚动手势**：手指明明是想在聊天流或列表里快速向下滑动浏览，由于没有位移快速判定，定时器在滑动途中触发，在半空中硬生生弹出一张菜单，严重阻碍正常阅读（幽灵菜单）；
- **做成全屏居中大弹窗**：长按一条聊天气泡，却弹出一个居中半透明强遮罩对话框，挡住上下文其他消息，用户无法对照前因后果；
- **菜单在屏幕边缘被裁剪切断**：当长按靠近屏幕底边或右边缘的消息时，菜单仍然机械地向右下方展开，导致后两项操作直接溢出视口被截断。

用居中强阻断弹窗或无消歧长按去扛触控单项操作，不是打断连续阅读动线，就是手势与滚屏频繁互掐。

## 规则

移动端触控上下文菜单遵循**微缩触觉反馈 + 460ms 时间门限 + 10px 欧氏位移注销 + 就近贴附边界翻转**模型。

| 阶段 | 物理与几何规则 | 体验与系统行为 |
| --- | --- | --- |
| **按下微缩反馈** | `pointerdown` 瞬间应用 `scale(0.98)` 轻微内陷形变 | 给用户提供明确的物理「正在按压」触觉暗示，建立心理预期 |
| **460ms 时间门限** | 启动 460ms 高精度定时器与进度插值 | 短促轻触（< 250ms）判定为普通点击；长按满 460ms 触发菜单 |
| **10px 欧氏位移注销** | 实时监测 $\sqrt{\Delta x^2 + \Delta y^2}$。若 $> 10\text{px}$ 立即清空定时器 | 容忍 10px 内微弱颤动；位移超标瞬时让路给列表原生顺畅滚动 |
| **视口边界夹紧与翻转** | 菜单就近锚定在触控点；横向在视口 padding 内 clamp；纵向若探出底边则翻转至气泡上方展开 | 绝不溢出可视窗口，始终保持 100% 可见可点 |
| **轻遮罩点外即关** | 背景挂载轻量级半透明 scrim，点击任意空白处或滚动即瞬时收回 | 操作用完即走，极低认知负荷 |

最容易混的几对：

- **长按上下文菜单不是长按多选。** 长按上下文菜单针对当前单条记录弹出就近操作（复制/回复/转发），不改变页面模式；长按选择（`press-select`）是将整页切换至带复选框的批量管理态。
- **长按上下文菜单不是桌面 Popover。** 桌面气泡弹层（`overlay-taxonomy`）是通过鼠标精确点击静态按钮触发；触控长按菜单是用户手指在可滚动内容流上通过时间累积就地唤起，必须带手抖位移消歧。
- **长按上下文菜单不是长按蓄力确认。** 长按蓄力（`confirm-taxonomy`）是长按 2 秒用进度环作为危险操作的拦截防线；上下文菜单是快捷功能入口。

说清楚一次长按上下文菜单，用三件事（交互公式）：

1. **名称** — 触控长按上下文菜单（Touch Context Menu）
2. **触发手势** — 原地长按气泡 ~460ms
3. **展开结果** — 就近就地弹出单条操作，边缘自动避让翻转

## 和「居中弹窗 / 无消歧长按」的差别

| | 全屏居中弹窗 | 无消歧长按 | 460ms 消歧 + 就近避让菜单 |
| --- | --- | --- | --- |
| 打断程度 | 强打断，遮挡整屏聊天上下文 | 容易卡死滚屏 | **弱打断，聊天内容仍清晰可辨** |
| 滑动共存 | 容易误吞滑动 | 滚屏途中频繁冒出幽灵菜单 | **10px 位移立即销毁定时器，滑屏丝滑** |
| 定位精度 | 视口死板居中 | 容易溢出视口下边缘 | **紧贴触控点，底边自动向上翻转** |
| 操作成本 | 必须找取消按钮 | 点击空白关 | **轻量 scrim 遮罩，点任意处即关** |

## 机器

状态机在无 DOM 的纯算法模块里：`shouldCancelHold`（计算欧氏位移是否超出容差门限）、`calcClampedMenuPosition`（视口四向边界安全夹紧与底边碰撞翻转计算）、`calcHoldProgress`（0 到 1 归一化蓄力进度）。
