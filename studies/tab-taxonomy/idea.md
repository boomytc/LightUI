# 页签

一排标签只说了能切。真正要先定的是**选中态是哪种模型**。

## 问题

「做个 Tab」描述的是外观：几个标题横着排，点一下换一块内容。真正会坏掉的是**选中态和切换反馈对不上机器**：

- 短线拉满整格，看起来像在扫按钮而不是扫文字
- 卡片式还留着底边，页签和面板之间有一条缝
- 有先后顺序的流程被做成互斥的平级页签，完成态看不见
- 同一份数据的切片被做成整页切换，布局跟着跳
- 文件夹页签没有压住下层，斜切只是装饰
- 预览缩略图和高清主图不是同一张，切过去对不上

用同一种下划线去扛这些差异，不是缝露馅，就是步骤看不出进度，就是切视图时整页重排。

## 规则

先按「选中态改什么、内容怎么换」选模型，再谈皮肤。

| 模型 | 选中态 | 切换时 |
| --- | --- | --- |
| 线性滑块 | 等宽排文字；**2px 短线跟着文字 span**，不是整格 | 只过渡 `left` / `width`；内容淡入。首次测量关掉过渡，避免从 0 滑入 |
| 卡片 | 未选中是独立浅底卡片；选中变与面板同色、**去掉底边**，`margin-bottom: -1px` 盖住顶边 | 第一项选中时去掉面板左上圆角，避免旁侧露缝 |
| 鱼骨步骤 | 箭头首尾咬合；点到哪一步，**它之前是完成、它是当前、之后是未开始** | 当前铺满，完成次之，未开始浅底。不是平级互斥 |
| 分段控件 | 同一条圆角轨道里，**白块滑到点击项** | 只换同一份数据的切片，不换页面结构；选项不超过四个 |
| 文件夹 | 左 90°、右 30° 斜切；选中项 **z-index 最高**，和文件列表同一块底 | 未选中压在浅色底条上，像叠着的纸 |
| 图片预览 | 缩略图就是标签；选中项描边抬起 | 主图与缩略图同一资源；主图 opacity 交叉淡入 |

最容易混的三对：

- **线性不是分段。** 线性是一排栏目，短线量的是文字。分段是同一轨道里的切片，滑块量的是整项。
- **卡片不是文件夹。** 卡片去掉底边，和面板连成一块。文件夹是斜切叠纸，选中项压在最上层。
- **鱼骨不是平级页签。** 完成态由「在当前之前」决定，不是四个互斥视图。四个同级栏目不该用箭头咬合。

说清楚一条页签，用三件事：

1. **名称** — 不要说「Tab」
2. **场景** — 同级栏目、流程步骤、同一数据的切片，还是看图
3. **规则** — 短线跟文字、去底边连面板、三态箭头、轨道滑块、叠纸，还是缩略图本身

## 和「再加一条下划线」的差别

| | 一律下划线 | 按选中模型分 |
| --- | --- | --- |
| 后台同级栏目 | 短线拉满格子，手感在扫按钮 | 短线对着文字滑过去 |
| 成员 / 权限分区 | 页签浮在面板上，中间一条缝 | 选中项与面板同色、去底边，连成一块 |
| 结账步骤 | 看不出做完了哪一步 | 箭头咬合，完成 / 当前 / 未开始 |
| 今日 / 本月 | 整页换成另一张报表 | 同一轨道里滑块，数字切片更新 |
| 项目资料 | 斜切只是 CSS 装饰 | 选中页签压住下层，和列表同一块底 |
| 空间预览 | 缩略图是另一套图 | 点哪张，Banner 就是哪张 |

## 机器

几何在无 DOM 的模块里：`textIndicator`（线性量文字，分段量整项）、`indicatorTransition`、`stepKind`、`cardPanelRadius`、`folderLayer`、`bevelInset`。
