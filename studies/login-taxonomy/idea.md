# 登录

「做个登录页」只说了有表单。真正要先定的是**登录是一张卡、分栏、沉浸、角色入口，还是分步**。

## 问题

「做个登录」描述的是外观：邮箱、密码、一个按钮。真正会坏掉的是**进门的舞台和产品对不上**：

- 稳妥的工具做成全幅海报，进来的人找不到卡
- 要讲品牌的创作台，却只剩一张白卡漂在空白里
- 旅行、活动的氛围被框进 SaaS 卡片，气势没了
- 个人端和企业端字段不同，却挤在同一张长表里猜
- 邮箱、验证、密码一次铺开，一屏做三件事

用同一种居中白卡去扛这些差异，不是品牌没地方站，就是身份没入口，就是字段把人吓回去。

## 规则

先按「进门怎么站」选舞台，再谈皮肤。字段是假的——这一则不问鉴权，只问摆法。

| 舞台 | 何时 | 机器 |
| --- | --- | --- |
| 居中卡片 | 稳妥 SaaS、通用工具 | **一格**；卡悬浮，页面留白 |
| 左右分栏 | 左品牌、右表单 | **两格**；`paneCount` 为 2 |
| 沉浸背景 | 全幅图或渐变上叠 | **一格**；表单叠在底上，不是第二栏 |
| 角色入口 | 身份不同、字段不同 | **先选身份**；`needsRole` |
| 分步 | 邮箱 → 验证 → 密码 | **一屏一事**；`isStepped`；不是一张长表 |

最容易混的四对：

- **登录卡怎么摆不是整页骨架。** 卡片悬浮、分栏、沉浸，回答的是进门舞台。这一页其余怎么铺，是骨架。
- **登录不是卖点首屏。** 首屏卖的是承诺。登录要的是进得去。
- **分栏不是沉浸。** 分栏是两格：品牌一块、表单一块。沉浸是同一块底，表单叠上去。
- **角色入口不是分步。** 角色是先选身份再进表单。分步是同一身份里，一屏只填一件事。

说清楚一个登录，用三件事：

1. **名称** — 不要说「做个登录页」
2. **场景** — 稳妥工具、品牌分栏、氛围、先选身份，还是字段太多
3. **规则** — 一格悬浮、两格品牌、叠在底上、先选角色、一屏一事

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律居中白卡」的差别

| | 一律白卡 | 按舞台分 |
| --- | --- | --- |
| SaaS 工作台 | 碰巧对了 | 卡悬浮，留白充足 |
| 创作工坊 | 品牌没地方站 | 左品牌，右表单 |
| 旅行账户 | 海报被裁进卡片 | 全幅底上叠表单 |
| 个人 / 企业 | 两套字段挤一张表 | 先选身份，再进各自表单 |
| 验证步骤多 | 一屏三个问题 | 邮箱再密码，一屏一件事 |

## 机器

判断在无 DOM 的模块里：`paneCount`、`isStepped`、`needsRole`。只有左右分栏是两格。只有角色入口要先选身份。只有分步按屏前进。
