# 视线

指针偏了，视线落到图集格子。半径里平滑，格子外夹紧，眨眼走另一行。

## 问题

一张会看人的脸，若按指针角度连续转，图集对不上，中间帧是捏出来的。若指针一动就跳到最远的格子，近处微调会抖。把两张脸叠成一格、或换格时播叠化，都会闪、会露出双鼻子。

## 规则

把指针相对原点的偏移除以半径，得到 `[-1, 1]` 的看向向量；长度超过 1 就夹到圆上。每一帧用指数平滑追这个向量，再量化到 12×3 格子：

```
col = round((lookX * 0.5 + 0.5) * 11)
row = round((lookY * 0.5 + 0.5) * 2)
```

图集只存独立姿势。换格硬切到下一格，不播重叠。

眨眼不是旋转，是同一格的另一行（源行 = row + 3）。自动眨眼只切换源行，不改 look 向量。

## 和「连续转头」的差别

| | 连续转 / 叠化换格 | 平滑后量化 |
| --- | --- | --- |
| 图集 | 没有的中间角度要捏，或把两张脸叠成一格 | 只抽已有格子 |
| 换格 | 叠化会闪、会露出双脸 | 硬切到下一格独立姿势 |
| 半径外 | 一直跟着飞 | 夹在圆上，看向保持满格 |
| 眨眼 | 另做一套旋转 | 同一格换一行 |
