「做个计时器」描述的是一个在走的数字。用户真正撞上的，是方向搞反。

自由学习被画成 25 分钟上限的假番茄，到点假装完成。专注一段，数字却越走越大，人不知道还剩多久。到点弹一条 toast，数字继续跑成负数。这些看起来都是计时器，方向却不是同一个。

先问三件事：名称、场景、这一段往上加还是从 N 分钟往下走。

- **累计**：没有会话上限，数字是已经过了多久。
- **专注**：从 N 分钟往下，数字是还剩多久；到 0 自己停住，不要变负数，也不要弹 toast。

最容易混的一对是累计和专注。把倒数做成越走越大，或把累计做成有上限的假番茄，都会坏。进行中切走，顶栏仍要露出这一段，那不是第三种计时器。

进度能不能算不是这一段往上还是往下，见 [进度](/s/progress-taxonomy)。专注到点不是一条 toast，见 [提示](/s/notify-taxonomy)。问题怎么串，见 [图谱](/graph)。
