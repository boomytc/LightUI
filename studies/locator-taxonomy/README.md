# @lightui/locator-taxonomy

In-page locator taxonomy for long pages: reading progress, back to top, anchor TOC, stepper, accordion, search, and status filter.

## Development

```bash
make dev-study STUDY=locator-taxonomy
# Or directly:
npm run dev --workspace=@lightui/locator-taxonomy
```

Standalone playground runs at `http://127.0.0.1:5212/`.
