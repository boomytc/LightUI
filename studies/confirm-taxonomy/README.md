# @lightui/confirm-taxonomy

Confirmation ladder and destructive action safeguards taxonomy: undo toast, hold-to-confirm, swipe-to-reveal, popconfirm, modal dialog, type-to-confirm, and consequence checklist.

## Development

```bash
make dev-study STUDY=confirm-taxonomy
# Or directly:
npm run dev --workspace=@lightui/confirm-taxonomy
```

Standalone playground runs at `http://127.0.0.1:5213/`.
