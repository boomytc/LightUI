# fill-taxonomy

「做个表单」不是同一种东西。先问填写前、填写中、提交后这一栏该交代什么：标签常在、必填先标、错在栏下能改，还是成功带下一步。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5208/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/fill-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 标签：在没有标签的框里输入几个字，占位符没了
2. 必填：提前标出姓名的星号和公司的「选填」
3. 说明：对照叠了两行的错误，和替换成一行的写法
4. 分组：对照一串排到底，和已知事实只读
5. 占位：给出格式提示，席位预选标准席
6. 当场能改：对照同一截短号码：页顶一句失败，对不上栏；栏下还差几位，带着改法
7. 成功：对照只写「成功」，和带确认邮箱、下一步的结果
