# 引导

教学不是弹窗，也不是一条提示。真正要先定的是**何时出现、钉在谁身上、靠什么推进、结束后还挡不挡**。

## 问题

「做个新手引导」描述的是外观：一块东西指着按钮说话。真正会坏掉的是**出现时机、锚点、推进和残留对不上**：

- 第一次进工作台被做成必须点确定的居中弹窗，整页被挡住，真实按钮点不到
- 新功能用未读角标来喊，数字卸不掉，也教不会怎么用
- 空标题弹出一句校验红字，人还没开始填就已经被骂
- 教完了遮罩还在，清单却在 100% 时被卸掉
- 聚光挖孔被当成卡片内凹角，孔不跟控件走
- 漫游没有跳过，每一步都要挨打

用同一种「弹一层教学」去扛这些差异，不是把人关在门外，就是教完了还挡着，就是该钉住的没钉住。

## 规则

先问何时出现、钉谁、怎么推进、教完还在不在，再谈皮肤。

| 模型 | 推进 | 挡住外面 | 教完还在 |
| --- | --- | --- | --- |
| 漫游 | **下一步**（可跳过） | 是，遮罩挖孔跟着目标 | 否 |
| 教练 | **明白了** | 否，页面仍可点 | 否 |
| 热点 | **未读 → 打开 → 已读** | 否 | 否，圆点卸掉 |
| 聚光 | **点挖出的那个控件** | 是 | 否 |
| 清单 | **勾完任务** | 否 | 是，100% 仍留着 |
| 空态 | **字段被填上就卸掉** | 否 | 否 |

最容易混的三对：

- **聚光不是确认弹窗。** 聚光挡住外面，是为了逼人手点那个控件。确认弹窗问的是要不要做，挖孔里没有真实按钮。
- **热点不是未读角标。** 角标叠数字。热点教一个新功能：点开读完，圆点卸掉。
- **空态提示不是校验报错。** 提示在字段还空着时出现，填上就走。校验是填错了才开口。

挖孔是为了露出要教的控件，不是给卡片挖一枚锁标。

说清楚一种引导，用三件事：

1. **名称** — 不要说「新手引导」
2. **场景** — 第一次进工作台、新功能、空着的标题，还是入门清单
3. **规则** — 何时出现、钉在谁身上、靠什么推进、结束后还挡不挡

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律做成教学弹窗」的差别

| | 一律教学弹窗 | 按出现 / 锚点 / 推进分 |
| --- | --- | --- |
| 第一次进工作台 | 居中大卡，真实按钮点不到 | 漫游挖孔，下一步或跳过 |
| 发布按钮旁一句 | 整页变暗 | 教练气泡，页面仍可点 |
| 新功能 | 未读数字一直挂着 | 热点点开读完，圆点卸掉 |
| 必须动手 | 有「下一步」却点不到控件 | 聚光没有下一步，点洞里的控件才走 |
| 入门四件事 | 做完引导卸掉 | 清单到 100% 标题换成入门完成，列表还在 |
| 空标题 | 红字校验 | 填上就卸掉的提示 |

## 机器

判断在无 DOM 的模块里：`guideAdvance`、`guideBlocksOutside`、`guidePersists`、`allowsSkip`、`hotspotNext`、`hintActive`、`tourStep`、`checklistProgress`、`cutoutPad`。
