# path-morph

矢量路径变形：2D Procrustes 相似分解与极坐标插值 vs 朴素坐标线性插值。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5214/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/path-morph`。

建议按这个顺序观察对照：

1. **右箭头 ↔ 下箭头**：观察 90° 旋转时，Polar 模式绕质心饱满转动，而 Linear 模式沿弦长抄近路向内收缩 30%
2. **汉堡菜单 ↔ 关闭**：观察 λ 偏置如何自动选取最短 ±45° 折叠，杜绝 135° 大翻转
3. **播放 ↔ 暂停**：观察 1 条多边形子路径如何满射分裂为 2 根圆柱（细胞分裂），不凭空坍缩
4. **正方形 ↔ 菱形**：观察闭合路径循环对齐与角点锚定
5. **打开几何探针**：观察采样点分布、质心与实时旋转角 $\theta^*$、缩放比 $\sigma^*$ 计算

舞台查询：`?stage=1&preset=arrow-turn&t=0.5&mode=polar`。
