# 图表

「做个图表」只说了有数。真正要先定的是**这组数据要看什么**。

## 问题

「做个图表」描述的是外观：有数，就要画。真正会坏掉的是**意图和痕迹对不上**：

- 月份被切成饼，涨跌看不出来
- 城市全称竖着挤，名字转 45° 才塞得下
- 无序品类被折线硬连，好像有先后
- 广告投入和销量被画成两条线，点与点其实没有时间顺序
- 曝光、点击、付费被并排成柱，看不出哪步在掉
- 六项能力排成六根柱，看不出全面还是偏科

用同一种饼或竖柱去扛这些差异，不是趋势被切碎，就是名字转角，就是把无关的点连成故事。

选对图也不是看板下钻。先定这组数据要看什么。一层层点进去，换的是粒度，不是图种。

## 规则

先问意图，再选痕迹。皮肤、配色、3D 都在后面。

| 意图 | 问的是 | 痕迹 |
| --- | --- | --- |
| 看变化 | 时间上怎么走 | 折线。还要体积 → 面积。横轴等间距时间；缺测断开。无序类别不要硬连 |
| 比大小 | 谁多谁少、谁排前面 | 短名竖柱；长名或排名横条。轴从 0 起 |
| 看占比 | 整体怎么切、内部怎么拆 | ≤5 类环形，从 12 点起；内部再拆用堆叠。不是趋势 |
| 看关系 | 两个东西是不是一起变 | 两个连续数 → 散点；两个维度 × 强弱 → 热力 |
| 看流程 | 一步步转化掉在哪 | 漏斗。上一步是下一步的全集：曝光 → 点击 → 付费 |
| 看能力 | 多项打分，全面还是偏科 | 雷达。5–7 维，全部 0–100，轴从 0 |

最容易混的三对：

- **选对图不是看板下钻。** 先定这组数据要看变化、大小、占比、关系、流程还是能力。一层层点进去，换的是粒度，不是图种。
- **时间趋势不要用饼。** 饼没有从左到右。月份是时间，不是份额。
- **长名字不要竖柱。** 名字会挤、会转角。排名或城市全称用横条，文字横着写全。

说清楚一张图，用三件事：

1. **名称** — 不要说「做个图表」
2. **场景** — 看变化、比大小、占比、关系、流程还是能力
3. **规则** — 时间才连线、轴从 0、饼不超过 5 片、漏斗有先后包含

## 和「一律饼图或竖柱」的差别

| | 一律饼图或竖柱 | 先问要看什么 |
| --- | --- | --- |
| 月销售趋势 | 十二块饼，看不出涨跌 | 折线，时间从左到右 |
| 城市订单榜 | 竖柱把名字转 45° | 横条，名字横着写全 |
| 预算五类 | 再切十二块，或 3D 饼 | 环形，从 12 点起 |
| 广告 vs 销量 | 两条折线硬连 | 散点，看相不相关 |
| 曝光到付费 | 柱子并排比大小 | 漏斗，上一步是全集 |
| 六项能力 | 六根柱子 | 雷达，全面还是偏科 |

## 机器

决策在无 DOM 的模块里：`intentOf`（叶子就是问题）、`markFor(intent, followup)`、`axisFromZero`、`tooManyForPie`（>5）、`lineRequiresTime`（只有「看变化」才连线）。
