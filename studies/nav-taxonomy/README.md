# nav-taxonomy

看起来都是导航，住在哪、怎么开、滚的时候干什么却完全不同。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5177/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/nav-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 悬浮吸顶：离顶浮卡，`sticky` 不是 `fixed`
2. 侧栏：竖排主导航；五种空间模型在另一则
3. 面包屑：路径，最后一项不能点
4. 二级下拉：一列子页
5. 巨型菜单：多列分类，小屏不要硬缩
6. 汉堡抽屉：从右侧滑，锁滚动
7. 全屏遮罩：整页换成大字菜单
8. 锚点：滚到哪高亮哪；点击时锁观察器
9. 滚动收缩：进入 40、退出 16
