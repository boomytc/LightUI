# 对齐

对齐不是「看起来正」。真正要先定的是**对齐的是基线、焦点、数位，还是盒子**。

## 问题

「帮我对齐一下」描述的是观感。真正会坏掉的是**对错了东西**：

- 价格「128」和「元/月」按外框 `items-center`，基线一高一低
- 封面用 `contain` 留出空带，看起来像裁偏了；或 `cover` 却停在 `50% 50%`，主体被切走
- 图标和文字没说交叉轴，图标就往上飘
- 间距靠子孙 `margin` 目测，一处改、别处又缝
- 第一行贴着盒子顶，`padding-top` 没按行高 / 帽高留
- 圆和方、大小字按几何中心，视觉上却矮一截
- 浮层用 `translate` 猜像素，换尺寸就歪
- 费用账单金额左对齐、未补小数、用比例数字，个位十位参差错开无法比大小
- 列表状态紧随标题漂移，右侧参差不齐破坏纵向扫读
- 容器居中顺手居中正文，长文行首随行宽跳动，阅读视线反复找起点
- 结果反馈整页无差别居中，打散详细键值对并争抢中轴

把这些都当成「再往中间挪一点」，不是基线错了，就是焦点切了，就是盒子对上了、眼睛没对上。

## 规则

先问对齐的是哪一种，再写 CSS。十一句对应十一个开关。

| 咒语 | 对齐的是 | 对 | 错 |
| --- | --- | --- | --- |
| 基线 | 文字基线 | `align-items: baseline` | `items-center` 对外框 |
| 封面 | 画面焦点 | `object-fit: cover`，`object-position` 跟着主体（如 `50% 88%`） | `contain` 留空，或默认 `50% 50%` |
| 交叉轴 | 盒子 | 图标+文字 `align-items: center` | 不说轴，图标自己飘 |
| 间距 | 缝 | 父级 `gap`，子孙 `margin: 0` | 随机 `margin` 目测 |
| 贴边 | 边缘 | `padding-top` 按行高 / 帽高 | 第一行贴顶 |
| 光学 | 视觉质量 | 圆略放大、三角略右移 | 几何中心 |
| 嵌入 | 边缘 | 绝对定位用 `inset` | `translate` 猜 |
| 数位 | 小数点与数位 | `text-right` + `tabular-nums` + 统一补齐小数 | `text-left`，比例数字，小数不齐 |
| 两端 | 左右边与扫读线 | `justify-between`，状态贴右垂直成列 | `justify-start`，状态紧跟标题漂移 |
| 读线 | 文字起跑线 | 容器居中，文本 `text-align: left` | 容器居中顺手文字居中，行首跳动 |
| 中轴 | 结果焦点与明细分层 | 结果沿垂直中轴，明细回归左对齐 | 全页无差别居中争抢中轴，打散键值 |

封面是同一件事的两面：先填满，再把焦点放在主体上。主体不在画面中心时，`cover` 加默认居中等于瞎切。

光学对齐仍是在放盒子，只是不以包围盒的几何中心为准：圆看起来比同尺寸的方小，播放三角的视觉质量偏左。

比较数字靠数位对齐，表格与金额必须右对齐配合 `tabular-nums`，否则比例字体会让 1 比 9 窄扯歪小数点。

连续阅读需要固定的左侧起跑线，容器居中绝不等于文本居中；强结果卡片的核心动作沿中轴放大，辅助明细必须回归左对齐。

## 和「再往中间挪」的差别

| | 目测居中 | 先问对齐什么 |
| --- | --- | --- |
| 价格 + 单位 | 外框中线，基线错位 | 一条文字基线 |
| 竖图裁成方 | 空带，或把头切掉 | 填满，焦点跟着人走 |
| 图标行 | 图标顶对齐 | 交叉轴居中 |
| 卡片节奏 | 每项自己 margin | 一条 gap |
| 大标题 | 贴着顶边 | 帽高对上内边距 |
| 圆钮里的三角 | 几何正中，看起来偏左 | 略向右光学偏移 |
| 浮层 | translate 猜 | inset 四边 |
| 费用明细 | 左对齐比例数字，数位错乱 | 右对齐 + 等宽数位 + 对齐小数点 |
| 列表状态 | 紧随标题，右边缘忽左忽右 | 两端贴边，右侧垂直扫读线 |
| 居中卡片长文 | 文字居中，每行起点跳动 | 容器居中，文本共用左起跑线 |
| 成功反馈卡 | 明细全部居中抢中轴 | 结果沿中轴放大，明细左对齐分层 |

换骨架是另一件事。这里只回答这一条缝对在哪。
