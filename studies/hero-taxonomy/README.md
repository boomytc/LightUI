# hero-taxonomy

一块首屏不是同一种东西。先定打开第一眼要回答什么，再谈外观。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5191/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/hero-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 产品介绍：能解决什么？左价值、右产品、底信任
2. 个人品牌：你是谁、做得怎样？杂志 Banner、头像、代表作
3. 活动召唤：为什么现在参加？主题、时间地点、唯一主行动、席位
4. 电商：卖什么、值不值得？一件主推，不要五张海报
5. 媒体：发生了什么？头条、摘要、时间来源
6. 课程：能学到什么？成果承诺 + 作品切片，不是大纲
7. 工具：能帮我做什么？一句话能力，当场可试
8. 社区：谁在这里？人与话题，不是产品卖点
