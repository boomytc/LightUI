# 给导航起对名字

「做个导航栏」只说了有一排链接。真正要先定的是**它住在哪、怎么打开、滚的时候干什么**。

## 问题

站点导航看起来都是几个入口。会坏掉的是模型对不上：

- 浮卡用了 `fixed`，内容被盖住，自己还要补一层 padding
- 面包屑被当成主导航，深层页没有别的入口
- 小屏把巨型菜单缩到 390px，点不到、看不全
- 抽屉打开后底下的页面跟着滑
- 锚点点了高亮来回跳，因为滚动时观察器没锁
- 透明顶栏白字叠在浅色大图上

用同一种「顶栏 + 下拉」去扛这些差异，不是挤、就是盖、就是在小屏上打不开。

## 规则

先按「放在哪、怎么展开、滚的时候变什么」选模型，再谈皮肤。

| 模型 | 它是什么 | 展开 / 滚动时 |
| --- | --- | --- |
| 悬浮吸顶 | 离顶的浮卡，占位 | `sticky`，不是 `fixed` |
| 侧栏 | 竖排主导航，占位 | 可折成图标；空间模型见另一则 |
| 面包屑 | **不是**主导航 | 最后一项是当前页，不能再点 |
| 二级下拉 | 栏目下的子页 | hover / 点开一行列表 |
| 巨型菜单 | 超过两级的站点 IA | 整宽多列，不是一行子链 |
| 汉堡抽屉 | 小屏主导航 | 从侧边滑入，锁滚动 |
| 全屏遮罩 | 项少、要仪式感 | 盖住整页，大字居中 |
| 锚点导航 | 长页分段 | 滚到哪高亮哪；点击时先锁观察器 |
| 滚动收缩 | 大图上的顶栏 | 过阈值变矮变实；进出用两道阈值 |

最容易混的三对：

- **抽屉不是全屏。** 抽屉占一条边；全屏把页面换成菜单。
- **下拉不是巨型菜单。** 下拉是一列子页；巨型是多列分类。
- **收缩不是悬浮吸顶。** 收缩改的是顶栏自己的高度和对比度；吸顶改的是钉住的位置。

说清楚一条导航，用三件事：

1. **名称** — 不要说「导航栏」
2. **场景** — 官网、后台、文档、落地页、作品集、小屏
3. **规则** — 占位还是盖上来，hover 还是点开，滚的时候钉住、高亮还是变矮

## 和「再包一层顶栏」的差别

| | 一律顶栏下拉 | 按模型分 |
| --- | --- | --- |
| 作品集 | 通栏压着画面 | 浮卡离顶，或大图上先透明再收缩 |
| 后台 | 横向点不完 | 侧栏长期占位 |
| 从搜索进来的深层页 | 不知道自己在哪 | 面包屑是路径，不是主菜单 |
| 电商分类 | 一列子链看不全 | 巨型菜单按列归类 |
| 手机 | 巨型面板缩成一条缝 | 汉堡抽屉 |
| 长落地页 | 滚过了不知道在哪一节 | 锚点跟着高亮 |

## 机器

这里的二级下拉和巨型菜单是站点栏目，不是表单。侧栏这里只说明「竖排是一种主导航」。

状态机在无 DOM 的模块里：`crumbTrail`、`pickActive`、`nextShrunk`。
