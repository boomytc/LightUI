# 选控

「做个选择器」只说了能点。真正要先定的是**这一次选的是一个刻度、一段区间、按步加减、逐级路径，还是一段日期**。

## 问题

「做个选择器」描述的是外观：一块能点的控件。真正会坏掉的是**选的东西不同、却用同一种机器**：

- 体重做成输入框，人要自己对齐 0.1；或做成两个圆点，好像在选区间
- 价格做成两个独立输入，最低价可以高于最高价
- 购物袋数量做成尺子，滑来滑去才能到 2
- 省市区摊成一张长列表，或把「江苏省」当成最终值
- 入住离店做成两个日期框，中间那几天看不见，离店也可以早于入住

用同一个输入框或同一个下拉去扛这些差异，不是对不齐刻度，就是两端交叉、步长不对、上级改了下级还在、日期段对不上。

## 规则

已经确定是「选」之后，先问选什么，再落到一种机器。填还是选是上一问。往下展开提交什么、滚轮怎么吸附，是另外两问。

| 叶子 | 何时 | 机器 |
| --- | --- | --- |
| 滑动标尺 | 一个连续刻度上的数值（身高、体重） | 指针固定，刻度横向滑动，松手对齐最近步长 |
| 范围滑块 | 同时要下限和上限（价格、面积） | 两个端点，实时显示，端点不能交叉 |
| 步进器 | 少量、固定步长的个数（份数、件数） | 每次加减一个步长，到下限禁用减号 |
| 级联选择 | 先上级再下级的路径（省市区） | 选项随上级变；更换上级时清空下级 |
| 日期范围 | 日历上的起止（入住与离店） | 先起后止，高亮中间，止必须晚于起；过去不可选 |

最容易混的几对：

- **尺子不是范围滑块。** 一个值对一根指针。两个端点才是区间。体重不要做成两个圆点。
- **步进器不是尺子。** 份数很少、每次 1 个，不要滑 0.1。到 1 时减号要停。
- **范围滑块不是两个独立框。** 两端联动，最低不能超过最高。
- **逐级路径不是往下展开的列，也不是 Combobox。** 一次只看当前级，换省则市和区都要重选。往下展开提交一条路径，是另一问。
- **日期范围不是两个日期框。** 日历上高亮整段，才能看见住几晚。止必须晚于起。
- **横向尺子不是滚轮。** 滚轮是有序离散的圆柱吸附。这一则的尺子是指针固定、刻度横滑。

说清楚一次选择，用三件事：

1. **名称** — 不要说「做个选择器」，说滑动标尺、范围滑块、步进器、级联选择或日期范围
2. **场景** — 一个刻度、两个端点、少量个数、层级路径，还是起止日期
3. **规则** — 松手对齐 / 端点不交叉 / 下限禁用 / 换上级清空下级 / 止晚于起

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律输入框或一个下拉」的差别

| | 一律输入框 / 下拉 | 按选什么分 |
| --- | --- | --- |
| 体重 | 键盘对齐 0.1，或 1200 项列表 | 尺子，指针固定，松手对齐 |
| 价格 | 两个框，最低可以高于最高 | 双端滑块，端点不交叉 |
| 购物袋 | 尺子滑到 2，或弹出键盘 | 步进器，每次 1，下限禁用 |
| 省市区 | 一张长列表，或把省当成最终值 | 逐级选，换省清空市和区 |
| 入住离店 | 两个 date 框，中间看不见 | 日历高亮整段，离店必须晚于入住 |

## 机器

判断在无 DOM 的模块里：`choosePicker`（one-tick / two-ends / few-steps / tree-path / date-span）、`snapRuler`、`applyRangeThumb`（端点间距）、`stepQty`（触底即停）、`cascadeSelect`（换上级即切掉下级）、`pickDate`（过去忽略，止晚于起）。
