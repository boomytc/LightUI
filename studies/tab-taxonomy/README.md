# tab-taxonomy

一排标签不是同一种东西。先按选中态选模型，再谈外观。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5181/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/tab-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 线性滑块：短线跟着文字走，不是整格按钮
2. 卡片式：选中项去底边，和面板连成一块
3. 鱼骨步骤：点到哪一步，它之前是完成、之后是未开始
4. 分段控件：同一轨道里滑块，数字切片更新，布局不跳
5. 文件夹：斜切叠纸，选中页签压在最上层
6. 图片预览：缩略图就是那张主图
