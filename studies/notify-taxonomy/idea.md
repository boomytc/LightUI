# 提示

报一条消息只说了要出声。真正要先定的是**这条提示该打断到哪一档**。

## 问题

「弹个提示」描述的是外观：屏幕上冒一行字。真正会坏掉的是**打断重量对不上**：

- 未读数被做成必须点掉的弹窗
- 保存成功挡住表单，还要再点确定
- 删除先问「确定吗」，而不是删完再给撤销
- 多条公告做成切画面的轮播
- 导出完成闪一下就没了，回看不了
- 密钥风险用两秒就消失的轻提示
- 系统维护只在当前页弹一次，换页就没了
- 空列表写成一条提示
- 进度条当成 toast

用同一种「弹一下」去扛这些差异，用户会被打断、错过，或把必须处理的风险当成可以忽略的结果。

## 规则

先按「要不要看见、要不要动手、能不能错过」选档，再谈皮肤。

| 档 | 何时 | 机器 |
| --- | --- | --- |
| 弱 · 角标 | 只标数字 | 叠在图标右上角；**0 时卸掉，不要留空圆点**；超过 99 显示 99+；不弹 |
| 弱 · 轻提示 | 只报结果 | 内容区中上，约 **2.4 秒**自动消失；无遮罩，表单不停 |
| 中 · 带操作的轻提示 | 还要一个即时动作 | 约 **5 秒**；附「撤销」；删完再给机会，不要先弹确定 |
| 中 · 跑马灯 | 多条轮流播 | 页头下方同一条里滚字；**悬停暂停**；不是切画面的轮播 |
| 中 · 消息中心 | 需要回看 | 写入铃铛后的列表；角标标未读；不打断当前工作 |
| 强 · 警告 | 必须看见、必须处理 | 固定在内容区；处理前不消失；**不是挡住整页的模态** |
| 强 · 全局通知条 | 影响整站 | 导航下方常驻；换页还在；用户手动关 |

最容易混的三对：

- **提示不是弹窗。** 提示不打断当前任务。必须先处理才能继续，才是弹窗。警告必须看见，但内容区仍可操作。
- **跑马灯不是轮播。** 跑马灯在同一条里轮流播字。轮播会把整块画面切走。
- **警告不是轻提示。** 风险不能两秒后消失。轻提示只报已经发生的结果。

数字角标和文字徽标是两种形态。这一则只教**数字角标**：0 卸掉。文字徽标（「新」「热」）标的是状态，不要拿来当未读数。

空状态不是一条提示。进度也不是轻提示。

说清楚一条提示，用三件事：

1. **名称** — 不要说「弹个提示」
2. **场景** — 未读数、保存成功、删完撤销、导出留档，还是整站维护
3. **规则** — 0 隐藏 / 约 2.4 秒消失 / 可撤销 / 留档 / 处理前不消失 / 跨页常驻

这三件事收成一句，就是卡片上的「说清楚」。复制出去就能当说明，不必另开一套说法。

## 和「一律弹一下」的差别

| | 一律弹窗或 toast | 按打断档分 |
| --- | --- | --- |
| 未读消息 | 每来一条就弹 | 角标叠数字，瞄一眼 |
| 保存资料 | 挡住表单点确定 | 轻提示 2.4 秒，手不离开输入 |
| 删除草稿 | 先问确定吗 | 立刻删，5 秒内可撤销 |
| 多条公告 | 大图轮播切屏 | 页头跑马灯，悬停暂停 |
| 导出完成 | 闪一下没了 | 写进消息中心，铃铛可回看 |
| 密钥泄露 | toast 两秒消失 | 警告钉在内容区，点立即重置才走 |
| 今晚维护 | 只在当前页出现 | 导航下的通知条，换页还在 |

## 机器

档位在无 DOM 的模块里：`weight`、`autoDismissMs`、`persists`、`needsAction`、`hideBadge`、`badgeLabel`、`interruptsTask`。七种叶子都不打断任务——包括警告。
