# 首屏

「做个高级首屏」只说了要花哨。真正要先定的是**打开第一眼要回答什么**。

## 问题

「做个 Hero」描述的是外观：一张大图、一句口号、两个按钮。真正会坏掉的是**第一屏的任务和站点类型对不上**：

- 产品页只剩空话，看不出能解决什么
- 作品集把履历堆上去，看不出你是谁、做得怎样
- 活动页先放报名，却没说为什么现在参加
- 电商轮播五张海报，主推和价格理由都看不见
- 媒体首屏塞满导航和订阅，看不出发生了什么
- 课程先列大纲，看不出能学到什么
- 工具先讲公司故事，当场却试不了
- 社区首屏在卖平台，看不见谁在这里

用同一种「高级大图 + 两个按钮」去扛这些差异，不是谁的问题都没回答，就是把登录卡、落地骨架和第一屏的任务混成一件事。

## 规则

先按「不滚动就要确认的那件事」选叶子，再谈皮肤。第一屏是第一折的**工作**，不是把首页模块挤进去，也不是做一张花哨海报。

| 叶子 | 第一眼 | 结构 |
| --- | --- | --- |
| 产品介绍 | **能解决什么？** | 左价值 + 右产品形态 + 底信任 |
| 个人品牌 | **你是谁、做得怎样？** | 杂志 Banner + 头像 + 代表作 |
| 活动召唤 | **为什么现在参加？** | 主题 + 时间地点 + **唯一主行动** + 席位 |
| 电商 | **卖什么、值不值得？** | 一件主推大图 + 价格理由 + 立即购买。**不要五张海报轮播** |
| 媒体 | **发生了什么？** | 头条 + 摘要 + 时间来源 |
| 课程 | **能学到什么？** | 成果承诺 + 作品切片，不是大纲列表 |
| 工具 | **能帮我做什么？** | 一句话能力 + **当场可试** |
| 社区 | **谁在这里？** | 人与话题，不是产品卖点 |

**一屏一个主行动。** `primaryCtaCount` 对每种叶子都是 1。次按钮可以有，但不能再做一个实心主按钮。

电商这一叶 `allowsCarousel` 为假：主推只能一件。`tooManyBanners` 在海报数大于 1 时为真。作品集的杂志 Banner 可以切代表作，那不是五张促销海报。

最容易混的三对：

- **落地骨架、全屏占满，都不是第一眼回答什么。** 落地页怎么铺、这一折占不占满视口，是整页骨架。这一则问的是**不滚动的那一眼要确认哪件事**。
- **首屏不是登录卡。** 登录卡在问你是谁、能不能进。第一屏在回答打开这一页的人此刻最关心的问题。
- **电商不是五张海报；课程不是大纲。** 店要卖一件主推。课要先承诺作品，再给大纲入口。

说清楚一块首屏，用三件事：

1. **名称** — 不要说「高级首屏」
2. **场景** — 打开这一页的人此刻要确认什么
3. **规则** — 第一眼给答案；一个主行动；电商不要五张海报

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律大图加两个按钮」的差别

| | 一律高级 Hero | 按第一眼的工作分 |
| --- | --- | --- |
| 协作产品 | 口号 + 演示按钮，看不出解决什么 | 左价值、右产品、底信任 |
| 设计师主页 | 履历墙 | 头像、代表作、风格 |
| 大会报名 | 两个一样重的按钮 | 主题、时间地点、唯一报名、席位 |
| 家具店 | 五张海报轮播 | 一件主推、价格理由、立即购买 |
| 行业早报 | 导航、订阅、广告挤在首屏 | 头条、摘要、时间来源 |
| 设计课 | 周次大纲列表 | 结课作品、切片、开课日 |
| 去背工具 | 公司故事 | 一句话能力，当场可试 |
| 开发者社区 | 平台卖点 | 此刻的人和话题 |

## 机器

判断在无 DOM 的模块里：`questionOf`、`primaryCtaCount`、`allowsCarousel`、`tooManyBanners`。每种叶子第一眼的问题不同；主行动永远是一个；电商不能轮播海报。
