# 布局

「做个页面」只说了有块。真正要先定的是**这一页的骨架是哪一种**。

## 问题

「做个网站」描述的是外观：有标题、有卡片、有一块主区。真正会坏掉的是**骨架和内容对不上**：

- 长文拉满整页，中文行长读不下去
- 转化页做成后台看板，承诺被数字挤走
- 图片被裁成一样高，或做成会切走整块的轮播
- 品牌首屏塞了三段介绍，气势没了
- 两边都是工作区，却拖不动，或做成盖上来的抽屉
- 要扫 KPI 的一页，被写成营销落地
- 一块一个主意的拼贴，被写成一整篇

用同一种「左右布局」去扛这些差异，不是阅读轴断了，就是官网变后台，就是瀑布变成轮播。

## 规则

先按「这一页怎么铺」选骨架，再谈皮肤。落地页和单栏还要带上节奏：栏间距 **24px**，区块之间 **64–96px**。模块卡、落地功能卡用网格拉齐行高，内部 `flex-col` + `mt-auto`，不要写死 `height`。

| 骨架 | 何时 | 机器 |
| --- | --- | --- |
| 单栏 | 安静读完 | 一条轴；**max-width ≈ 42rem（672px）**；图、引用也落在同一列 |
| 落地 | 转化、下载、预约 | 首屏承诺 → 证明带 → CTA；**不是仪表盘**；gutter 24px，区块 64–96px |
| 瀑布 | 图片高矮不一 | **不等高**；`break-inside: avoid`；不是轮播 |
| 全屏 | 第一眼记住一句话 | **一屏占满视口**；不要多段正文 |
| 分栏 | 两边都是工作区 | **两格**，中间一条可见分隔；可拖或固定；不是浮层抽屉 |
| 仪表盘 | 扫数字、比趋势 | KPI + 图 + 表的网格；左栏占位是侧栏的问题 |
| 模块拼贴 | 一块一个主意 | 卡片落在网格上；一行拉齐，底栏 `mt-auto` |

最容易混的四对：

- **整页骨架不是侧栏占位。** 骨架回答这一页怎么铺。靠左那一栏占不占位，是侧栏。
- **栏怎么铺不是顶栏去哪。** 顶栏住在哪、怎么开，是导航。
- **瀑布不是轮播。** 瀑布让卡片按列往下接。轮播会把整块画面切走。
- **分栏不是浮层抽屉。** 分栏两格都在文档流里。抽屉盖在当前任务上，用完就关。

说清楚一页骨架，用三件事：

1. **名称** — 不要说「做个页面」
2. **场景** — 长文、转化、图片流、海报首屏、双工作区、扫数字，还是一块一个主意
3. **规则** — 行宽、区块留白、不等高、一屏、两格分隔、KPI 网格，还是卡片网格

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律左右布局」的差别

| | 一律左右栏 | 按骨架分 |
| --- | --- | --- |
| 设计周刊 | 左侧目录，正文被挤窄 | 单栏 42rem，一条阅读轴 |
| 产品官网 | 后台导航 + 空白主区 | 落地：首屏、功能带、CTA |
| 灵感墙 | 等分九宫格或大图轮播 | 不等高瀑布，卡片不被拦腰截 |
| 发布会 | 首屏塞满介绍 | 一句话占满视口 |
| 编辑器 | 看起来像分栏，拖不动 | 两格工作区，中间一条可拖分隔 |
| 经营日报 | 大标题营销页 | KPI + 图 + 表 |
| 个人主页 | 一篇长文 | 一块一个主意的卡片网格 |

## 机器

判断在无 DOM 的模块里：`readingMeasurePx`、`isFullBleed`、`allowsUnevenHeight`、`splitPanes`。分栏拖拽用 `clampSplit`。
