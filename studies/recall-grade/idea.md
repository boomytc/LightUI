# 复习

翻开之后提交的是记得程度，还是只是下一张？先定这张牌**翻开是为了对照**，提交的是**间隔**，不是切走画面。

## 问题

「做个闪卡 / 翻卡片」描述的是外观：一面问题，一面答案，点一下换一张。真正会坏掉的是**提交的东西对不上**：

- 左右滑走下一张，没有打分，隔天还是同一堆
- 问题面上就能点「记得」，没对照就交了间隔
- 「忘了」和「模糊」都排到明天，次数也不动，两个按钮其实是同一个机器
- 今日无到期写成「暂无数据」，或弹一条 toast 就没了
- 三个记得程度做成「确认删除」那种弹窗，取消 / 确定，而不是间隔

用同一种轮播或确认框去扛这些差异，不是间隔乱了，就是人不知道刚提交的是什么。

## 规则

先问翻开之后要不要提交记得程度。再谈皮肤。

| 面 | 何时 | 机器 |
| --- | --- | --- |
| 问题 | 还没对照 | 只给「查看答案」；`canGrade` 为假 |
| 答案 | 题还在，对照「我的答案 / 正确答案」 | 三个程度；`applyGrade` 写 `reviewCount` 和 `nextReview` |
| 空 | 今日队列里没有 `nextReview <= today` | 图标 + 一句人话 + 一个按钮；不是「暂无数据」 |

三个程度不是同一天、同一次数：

- **忘了** — `reviewCount` 归零；`nextReview` 仍是今天，插回今日队列末尾。不是「明天，和模糊一样」。
- **模糊** — 次数不动；`nextReview` = 今天 + 1。
- **记得** — `reviewCount += 1`；间隔取 `[1, 3, 7, 14, 30]`，按新的次数封顶。

到期队列是 `dueCards`：只收 `nextReview <= today`。忘了的牌还在今天；模糊和记得的牌从今天队列里拿掉。

最容易混的三对：

- **复习不是轮播。** 轮播切画面。这里翻面是为了对照，提交的是记得程度。
- **空牌不是一条提示。** 提示瞄一眼就没了。今日无到期占着这块区域，告诉人为什么空、下一步点哪里。
- **打分不是确认弹窗。** 三个按钮是提交间隔，不是「要不要删」。

说清楚一次复习，用三件事：

1. **名称** — 不要说「翻卡片」，说复习打分
2. **场景** — 先看题，翻开对照，再提交忘了 / 模糊 / 记得
3. **规则** — 忘了归零并排到今天末尾；模糊明天；记得按 1、3、7、14、30 天

这三件事收成一句，就是卡片上的「说清楚」。

## 和「滑走下一张 / 两个按钮同一天」的差别

| | 滑走或忘了=模糊 | 按记得程度分 |
| --- | --- | --- |
| 还没翻开 | 就能点下一张或打分 | 只有「查看答案」 |
| 忘了 | 明天，次数不变 | 今天末尾再看，次数归零 |
| 模糊 | 和忘了同一天 | 明天，次数保留 |
| 记得 | 也许只是下一张 | 按间隔走开 |
| 今日无到期 | 「暂无数据」，或一条 toast | 人话空状态，一个按钮 |

## 机器

判断在无 DOM 的模块里：`dueCards`、`canGrade`、`applyGrade`、`intervalDays`、`nextIndexAfterGrade`（忘了把当前牌转到队尾；模糊 / 记得从队头拿掉）。日期是 ISO。
