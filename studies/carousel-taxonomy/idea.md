# 轮播

一组画面只说了会换。真正要先定的是**这一组画面怎么切**。

## 问题

「做个 Banner / 轮播」描述的是外观：几张图排成一组，会自己往下翻。真正会坏掉的是**切法对不上要提交的运动**：

- 品牌大图被做成硬切的左右滑，中间闪一刀
- 作品橱窗被压成一条轨道，侧面没有体积
- 推荐卡片排成 Banner，不能把顶上那张剥走
- 画册被做成平移，没有书脊
- 摄影墙被塞进圆点轮播，一次只能看一张
- 产品 360 被做成四张侧面照片左右滑
- 主视觉只有一层在动，没有远近
- 多条公告被做成切走整块画面
- 瀑布流被叫做轮播
- 表格的上一页 / 下一页被做成走马灯

用同一种 `translateX` 去扛这些差异，不是切得太硬，就是把不该换页的东西切走了。

## 规则

先问运动提交的是什么，再谈皮肤。

| 模型 | 切法 | 提交的运动 |
| --- | --- | --- |
| 经典左右滑 | 整页 `translateX` | 轨道只动画 `transform`；**圆点双向绑定当前页** |
| 淡入式 | 只改 `opacity` | **不要位移**，避免布局跳动 |
| 3D 旋转木马 | 中间大、两侧旋转 | 透视；点侧卡回到中间 |
| 卡片堆叠 | 剥走顶卡 | 下面几张略抬、略转；不是水平轨道 |
| 翻页式 | 沿书脊 `rotateY` | 左右两页同时可见 |
| 手风琴画廊 | 一项展开、其余收窄 | 改的是列宽，不是切走整屏 |
| 360° 旋转 | 转产品，不是幻灯片 | 拖的是角度 |
| 视差轮播 | 层以 0.3 / 0.7 / 1.0 错速 | 不是单层左右滑 |

控件词典里这一条对所有切法都成立：**圆点同步 index**；自动播放时**悬停暂停**；`prefers-reduced-motion` **关掉自动播放**；淡入如果还动，就只动透明度。

最容易混的三对：

- **切画面不是通知跑马灯。** 轮播把整块画面切走。跑马灯在同一条里滚字。
- **轮播不是瀑布布局。** 瀑布是同时看见多块。轮播是一组画面怎么前进。
- **列表翻页不是走马灯。** 上一页 / 下一页切的是表格的一页记录，不是一组海报在轨道上循环。翻页是分页，不要单开成一种轮播。

说清楚一组画面，用三件事：

1. **名称** — 不要说「轮播」
2. **场景** — Banner、橱窗、叠卡、画册、产品 360，还是主视觉
3. **规则** — 平移 / 只改透明度 / 木马 / 剥顶卡 / 翻页 / 手风琴 / 旋转产品 / 分层错速

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律左右滑加三个圆点」的差别

| | 一律左右滑 | 按切法分 |
| --- | --- | --- |
| 资讯头条 | 够用 | 整页平移，圆点同步 |
| 品牌大图 | 中间一刀硬切 | 叠在原位交叉淡入 |
| 作品集 | 侧面是扁的 | 中间大、两侧转出体积 |
| 今日推荐 | 得按箭头 | 把顶卡剥走 |
| 电子刊 | 没有书 | 沿书脊翻过去 |
| 摄影墙 | 一次只露一张 | 当前展开，旁边还露一条 |
| 硬件详情 | 四张侧面图在滑 | 按住转一圈 |
| 发布会主视觉 | 一层平移 | 远近错速 |
| 页头公告 | 整屏被切走 | 那是跑马灯，不是轮播 |

## 机器

判断在无 DOM 的模块里：`stepIndex`（经典默认 wrap）、`shouldAutoplay`（悬停或减少动效则否）、`fadeUsesOpacityOnly`、`transitionProps`、`isRotateNotSlide`。减少动效时淡入仍用透明度，其余直接跳到下一张。
