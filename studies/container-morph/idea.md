# 变形

同一入口连续变形。真正要先定的是**改宽、高、圆角还是排版**；停在展开态，或沿原路收回。

## 问题

「做一个变形」描述的是外观：一块东西变大了。真正会坏掉的是**改的轴和身份对不上**：

- 圆点变成胶囊，高度跟着晃，中心锚丢了
- 胶囊变成卡片，标题卸掉再装上，身份断一下
- 多出来的控件直接蹦出来，而不是沿 0fr 打开
- 只想改圆角，却连宽高一起放大，层级变成缩放
- 同一组节点要改成两列，却换成另一套 DOM
- 收回时淡出卸载整块，而不是内容先走、容器后收

用同一种 `scale` 去扛这些差异，不是身份断了，就是把层级当成放大。

## 规则

先问改哪根轴、锚在哪、内容跟不跟容器。再谈皮肤。

| 模型 | 轴 | 锚 | 规则 |
| --- | --- | --- | --- |
| 圆→胶囊 | **宽** | 中心 | 高度锁死，圆角全程 999。图标始终挂着 |
| 胶囊→卡片 | **高** | 顶 | 圆角 999→24。标题栏始终挂着。正文等容器长开再出现 |
| 紧凑条 | **尺寸 + 排版** | 左上 | 同一份内容身份。额外控件 `0fr→1fr` 打开 |
| 圆角 | **圆角** | — | 宽高锁死。这是层级，不是缩放 |
| 尺寸 | **尺寸** | 左上 | 内容层级不变，往右下长。不要重排节点 |
| 重排 | **排版** | — | 同一组节点，单列变两列，阅读顺序不变 |
| 反向收回 | **反向** | 中心 | 卡片→胶囊→圆点。内容先走，再收高度，再收宽度。勾留在最终的点里 |

最容易混的三对：

- **只改圆角不是放大。** 宽高锁死、只收圆角，说的是这块在层级里的位置。`scale` 把整块当成变大，身份还在，层级却糊了。
- **反向收回不是淡出卸载。** 沿原路走：正文先离开，容器再收成胶囊、再收成点。整块 `opacity: 0` 再卸掉，回来时是另一个入口。
- **内容重排不是换一套节点。** 单列变两列，DOM 还是那几个，阅读顺序还在。换成另一套卡片，是切画面，不是变形。

说清楚一次变形，用三件事：

1. **名称** — 不要说「做一个变形」
2. **场景** — 搜索条拉宽、通知展开、只改层级，还是沿路收回成点
3. **规则** — 改哪根轴、锚在哪、内容先于容器还是后于容器

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律 scale」的差别

| | 一律 scale | 按轴 / 路径分 |
| --- | --- | --- |
| 搜索圆点 | 整块放大，高度跟着晃 | 高度锁 48，从中心长宽 |
| 通知胶囊 | 标题卸掉，另开一张卡 | 标题始终挂着，只长高 |
| 层级变化 | 连尺寸一起放大 | 宽高不动，只改圆角 |
| 关掉 | 淡出卸载，再点是新入口 | 内容先走，容器后收，勾还在点里 |

变形不是新开一层，也不是切走整块画面，更不是侧栏把主区挤开。身份连续时，改的是这一块自己。

## 机器

判断在无 DOM 的模块里：`morphAxis`、`morphAnchor`、`locksSize`（仅圆角为真）、`keepsIdentity`、`reverseOrder`（仅反向为真）、`reverseBeat`（内容 → 高度 → 宽度）、`contentAfterContainer`、`morphBox`、`reverseBox`。减少动效时时长为 0。
