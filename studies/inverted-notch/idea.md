# 内凹角

内凹角该在父级挖孔。同色补丁缝回去，背景一变缝就露馅。

## 问题

卡片左上要嵌一枚锁标，锁标和卡片之间留一条缝，网格要从缝里透出来。

朴素做法是用伪元素 + 同色 `box-shadow` 把缺口「缝」回去。底色一变、一层半透明，缝就看见。`corner-shape: scoop` 写起来最短，但只能凹 `border-radius` 那一角，挖不出「锁标嵌进去」的孔，也留不出透底的缝。

## 规则

沿圆角矩形走一圈，到左上时绕过锁标外沿（三段反向圆弧）。缺口尺寸由锁标宽高加缝宽决定，同一组变量同时驱动锁标和裁切，所以悬停加宽锁标时，孔跟着长，弧线结构不变。

| 做法 | 孔由锁标驱动 | 能留透底缝 | 路径能插值 |
| --- | --- | --- | --- |
| `clip-path: shape()` | 是（CSS 变量） | 是 | 是 |
| `clip-path: path()` | 是（按像素重算） | 是 | 要重算 |
| `corner-shape: scoop` | 否 | 否 | 只动圆角 |

`shape()` 用 CSS 单位，Chrome 135+ / Safari 18.4+。不支持时回退到 `path()`。

## 和「缝回去」的差别

| | 同色补丁 / scoop | 在父级挖孔 |
| --- | --- | --- |
| 换背景 | 补丁颜色对不上 | 缺口仍是真裁切 |
| 锁标变宽 | 补丁对不齐 | `--chip-w` 带着孔一起长 |
| 半透明卡片 | 缝露馅 | 网格从孔里透出来 |
