# notify-taxonomy

报一条消息不是同一种东西。先定这条提示该打断到哪一档。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5184/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/notify-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 角标：0 时卸掉；点「增加未读」到 99+
2. 轻提示：保存后约 2.4 秒消失，表单还能改
3. 带操作的轻提示：删除草稿，点「撤销」回来
4. 跑马灯：三条轮流，悬停暂停，不是切画面
5. 消息中心：写入一条结果，铃铛里回看
6. 警告：钉在内容区，直到「立即重置」
7. 全局通知条：换两个假页面仍在，点 X 才关
