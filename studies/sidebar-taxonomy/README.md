# sidebar-taxonomy

靠左的导航不是同一种东西。先按占位和展开方式选模型，再谈外观。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5176/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/sidebar-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 悬浮岛：离边、占位、仍是一张卡
2. 弧形滚轮：只有基准线那一项是当前项
3. 多级：父级归类，子级才是页
4. 可折叠：宽度 240 → 72，主区跟着伸；折叠后仍占一条栏
5. 隐藏式：默认宽度为零，滑入盖住正文；Esc / 遮罩关闭
