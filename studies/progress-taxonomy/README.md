# progress-taxonomy

转圈只说了在等。先定进度能不能算：能算就走到 100 停住；不能算就循环，不要假百分比。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5186/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/progress-taxonomy`。

建议按这个顺序点一遍，对照会最清楚：

1. 平滑填充：点「开始」，scaleX 走到 100% 停住，不要循环
2. 阶段步骤：节点是工作本身（完成 / 当前 / 未开始），不是页签鱼骨
3. 环形百分比：从 12 点走到 100 停住
4. 液体填充：液面涨满停住
5. 循环同步：开口弧一直转，点「完成」才停，没有百分比
6. 雷达扫描：conic 扇区，不是普通转圈
7. 三点跳动：聊天等待，不要轨道
8. 音频波纹：竖条 scaleY，不要静态喇叭
