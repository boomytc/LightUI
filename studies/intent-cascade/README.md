# intent-cascade

多级菜单根据鼠标移动方向推测意图：斜向进入子菜单时不误切换。

理念说明见 [idea.md](idea.md)。

## 运行

独立 playground：

```bash
npm install
npm run dev
```

打开 `http://127.0.0.1:5174/`。

在 Lab 里打开：`make dev` → `http://127.0.0.1:5173/s/intent-cascade`。

建议先开「显示安全三角」，把指针放在「状态」上，再斜着滑向右侧「已取消」。途经负责人 / 优先级时，蓝色走廊应挡住切换。

## 对照

| 动作 | 期望 |
| --- | --- |
| 斜向滑向二级「已取消」 | 子菜单仍是状态列表 |
| 沿一级纵向移到「项目属性」 | 立刻换子菜单 |
| 项目属性 → 项目标签 → 斜向「紧急」 | 每一级都有自己的安全三角 |

关掉「意图预测」后，同样的斜线会途经即切换，方便对照。
