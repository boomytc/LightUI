# 展开

多出来的内容先问**撑开文档流，还是盖一层**。互斥还是独立，是流里的第二问。不要把抽屉再做一遍。

## 问题

「做个展开」描述的是外观：点一下，多出一块。真正会坏掉的是**这块东西占的位置对不上**：

- FAQ 做成绝对定位，后面的段落原地不动，答案盖住正文
- 本来可以同时打开的说明被做成手风琴，开 B 把 A 关了
- 行详情做成侧滑抽屉，对照不了这一行和下一行
- 树节点一点名字就展开，选中和开合糊在一起
- 读更多做成列表底部「加载更多」，把一篇文章变成翻页
- 卡片标题飞到浮层上，原来那张卡空了
- FAQ 手风琴被做成列宽画廊，内容树被做成主导航多级

用同一种盖一层去扛这些差异，不是把不该挡住的挡住，就是把该往下让的行钉死在原地。

## 规则

先问撑开还是盖一层，再谈皮肤。本则六种叶子都在流里：`coversPage` 一律是 false。盖一层是浮层的事——抽屉谈的是打断 / 贴附，本则不做。

| 模型 | 互斥 | 流里 |
| --- | --- | --- |
| 手风琴 | **是**（`openId`） | 一块开，另一块关；两块高度同时走 `0fr` / `1fr` |
| 折叠 | **否**（`Set`） | 几块可以同时开 |
| 树 | 每节点独立；**展开不是选中** | 箭头开合，名字选路径 |
| 行详情 | 详情跟这一行 | **必须插在这一行和下一行之间**，后面的行往下让 |
| 读更多 | 无 | 从 `line-height × n` 长到 `scrollHeight` |
| 卡片 | 无 | 同一张卡就地变高，标题还在流里；多出来的块先长高再淡入，关上反过来 |

错路只写在说明里，不做成一种叶子：把多出来的内容 `position: absolute` 盖住后面。行详情一旦盖住，下一行看不见，也对照不了。高度也不要猜 `max-height`。

最容易混的三对：

- **互斥不是独立折叠。** 手风琴开 B 必须关 A。折叠是几块都能开着，计数是 `OPEN n/total`。
- **行详情不是抽屉。** 详情跟这一行走，插在这一行下面，把后面的行撑下去。抽屉从边上滑进来，盖住当前任务。
- **读更多不是加载更多。** 读更多是这一块从三行高长到全文高。加载更多是列表末尾再接一页——那是列表变长，不是一块面板开合。

抽屉是另一问（打断 / 贴附），本则不做。FAQ 手风琴改的是文档高度，不是列宽画廊。内容树改的是这一页的开合，不是主导航多级。

说清楚一块展开，用三件事：

1. **名称** — 不要说「展开」
2. **场景** — FAQ、独立说明、内容树、行详情、读更多，还是就地变高的卡
3. **规则** — 撑开文档流，不是盖一层；互斥还是独立；高度走 `0fr` → `1fr`

这三件事收成一句，就是卡片上的「说清楚」。

## 和「一律做成浮层」的差别

| | 一律绝对定位盖住 | 按流内撑开 |
| --- | --- | --- |
| FAQ | 答案挡住后面的段 | 手风琴互斥，正文被撑下去 |
| 配送 / 退换 / 保修 | 只能看一块 | 三块可以同时开着 |
| 表格一行 | 详情浮在表上，下一行被盖 | 详情插在这一行下面，后面的行往下让 |
| 树 | 点名字又选中又展开 | 箭头只开合，名字只选路径 |
| 长文 | 列表底部再加载一页 | 这一块从三行长到全文 |
| 摘要卡 | 标题飞到另一层 | 同一张卡变高，标题还在流里 |

## 机器

判断在无 DOM 的模块里：`coversPage`、`exclusiveOpen`、`rowInFlow`、`toggleAccordion`、`toggleSet`、`treeToggleExpand`、`treeSelect`、`readMoreHeight`、`collapsedPx`。高度用 CSS grid `0fr` → `1fr`，不要猜 `max-height`。
